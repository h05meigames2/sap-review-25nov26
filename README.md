# One Star, Written in Sap

A programmatic entry for the make.fun bounty **"One Star, Written in Sap"** — one line, under 280 characters, in the voice of a houseplant leaving a 1-star review of its human owner. A real review with a real grievance (a watering schedule kept only as a rumor, a chipped pot, a sunless windowsill) and a clear reason for the single star.

## Run

```bash
python3 main.py
```

This writes the review to `/output/entry.txt` — a single UTF-8 line, 1–279 characters, no trailing newline.
